# PatchWell

PatchWell is a dependency vulnerability assessment tool that analyzes project manifest files or public GitHub repositories against the OSV and GitHub Advisory databases to identify known security vulnerabilities. The platform employs a large language model to translate raw vulnerability data into plain-language risk explanations, contextual severity scoring, patch guidance with breaking change analysis and remediation recommendations for unmaintained or unpatchable dependencies. Findings are consolidated into a risk-ranked executive report designed to support rapid remediation planning.

## Features

- **Manifest or repo input** - paste a dependency manifest directly or submit a public GitHub repository link
- **Vulnerability detection** - cross-references dependencies against the OSV and GitHub Advisory databases
- **Plain-language risk explanations** - AI-generated summaries that translate raw CVE data into clear, actionable context
- **Contextual risk scoring** - findings are weighted by factors like direct vs. transitive dependency and production vs. development scope, not just raw severity
- **Patch guidance** - AI-assisted upgrade guidance with awareness of likely breaking changes
- **Replacement suggestions** - recommended alternatives for abandoned or unpatchable packages
- **Executive summary** - a narrative overview synthesizing all findings into a single readable report
- **Result caching** - previously scanned repositories or manifests return instantly without re-running the full pipeline

## Getting started

### Prerequisites

- Docker and Docker Compose installed

### Setup

1. Clone the repository

```bash
   git clone git@github.com:LonlyEdward/PatchWell.git
   cd PatchWell
```

2. Copy the example environment file and fill in your own values

```bash
   cp .env.example .env
```

3. Start the application

```bash
   docker compose up --build
```

4. The backend will be available at `http://localhost:8000`

## How it works

1. A user submits a dependency manifest or a public GitHub repository URL.
2. PatchWell parses the manifest to extract a list of dependencies, distinguishing production from development packages.
3. Each dependency is checked against the OSV and GitHub Advisory databases for known vulnerabilities.
4. Findings are scored using both vulnerability severity and contextual factors (dependency scope and directness).
5. An AI model generates plain-language explanations, patch guidance and replacement suggestions for each finding.
6. All findings are synthesized into a risk ranked report with an executive summary.
7. Completed scans are cached, so identical future requests return instantly without repeating the full pipeline.

## Disclaimer

PatchWell is a learning project and is provided as-is, without warranty of any kind. Vulnerability data is sourced from OSV and the GitHub Advisory Database and may be incomplete or delayed. Risk explanations, patch guidance and replacement suggestions are generated by an AI model and may occasionally be inaccurate or incomplete hence they should be independently verified before being relied on for security critical decisions. PatchWell's contextual risk scoring is based on dependency metadata (e.g. direct vs. transitive, production vs. development scope), not full static analysis of your codebase and should be treated as a prioritization aid rather than a definitive risk assessment.
